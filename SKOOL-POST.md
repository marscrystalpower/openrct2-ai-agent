# Let your AI agent play RollerCoaster Tycoon 2

I've put together a bridge that lets an agent manage a park and build custom coaster tracks piece by piece.

You'll need a Windows PC, your own installed copy of RollerCoaster Tycoon 2, and an agent that can work with local files and run commands.

It runs through **OpenRCT2**: a community-built version of the game's engine that uses the graphics and sounds from your RCT2 installation. You'll launch OpenRCT2 for agent play. Your Steam game stays installed. OpenRCT2's plugin support is what makes the bridge possible.

**Repository:** https://github.com/FTPAiYT/openrct2-agent-bridge

Give that link to your agent and say:

> Read the README and AGENTS.md. Explain what OpenRCT2 is and what you need to install, then help me set up the bridge. Handle the technical steps for me. Don't launch or start playing until we've agreed on the park and what I want you to do.

This is a community test release. Agents can make mistakes and coaster designs still need train testing. Start with a new park or a copy of a save you care about. Never share your generated authentication config, installed plugin, saves or logs without reviewing them first.
